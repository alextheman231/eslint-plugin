This is a new minor release of the `@alextheman/eslint-plugin` package. It introduces new features and other backwards-compatible changes that should require little to no refactoring. Please read the description of changes below.
<!-- alex-c-line-release-summary-end -->

## Description of Changes

<!-- user-editable-section-start -->
- Enable the recommended config from `@eslint-community/eslint-comments`
  - This checks ESLint comments themselves to ensure they follow recommended best practices.
- Enable `@eslint-community/eslint-comments/require-description` on top of that.
  - This requires any disabled rule to include an explanation, making it clearer during code review and for future maintainers why the exception exists.

## Additional Notes

- So, we're really here linting ESLint comments with ESLint itself now. Very meta indeed.
